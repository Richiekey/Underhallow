# Underhallow Agent Directives

Refer to [docs/AGENT_CONSTITUTION.md](file:///c:/Users/HP/Documents/Underhallow/docs/AGENT_CONSTITUTION.md), [docs/FOUNDATION_SPECIFICATION.md](file:///c:/Users/HP/Documents/Underhallow/docs/FOUNDATION_SPECIFICATION.md), and the highest-level source of truth [docs/NORTH_STAR.md](file:///c:/Users/HP/Documents/Underhallow/docs/NORTH_STAR.md).

1. **The Prime Directive:** "Do not build Underhallow as a collection of features. Build it as a world. The player should experience: 'I'm a person living in this strange little world.'"
2. **Founder Authority:** Founder / Omni is the ultimate creative and product authority.
3. **The Underhallow Principle:** "Does this make Underhallow a better game?"
4. **Hierarchy of Truth:** North Star V1.0 → Foundation Specification → System Specifications → Technical Architecture → Agent Tasks → Implementation → Automated Tests → Human QA.
5. **No Drift:** Never deviate from the North Star or Foundation Specification without explicit Founder approval.
6. **Quality Standard:** Browser-first, 60 FPS, cozy isometric pixel art, clean architecture, single-player first with clean decoupled state.
